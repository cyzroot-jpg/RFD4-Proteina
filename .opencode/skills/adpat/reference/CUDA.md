# 项目规范性
在适配的过程中，要在当前项目的目录下新建一个'linshi'的目录，适配产生的文件都在这个目录下面，并且要有子目录进行隔离文件与文件，避免最后特别乱。
这样做可以保证原项目结构的不变，更干净。

TecoPyTorch提供了模型的自动迁移方法。只需在原始模型训练脚本中导入自动迁移代码，或者在运行模型训练脚本前设置自动迁移环境变量，即可实现训练模型从CUDA设备到太初AI加速卡上的迁移。

本文主要介绍如何使用自动迁移方法，进行模型迁移。

使用限制
模型的迁移约束，可参考迁移约束。

使用自动迁移方法迁移模型时，存在以下功能限制：

不支持torch.jit.script迁移。自动迁移方法使用了Python的动态图模式，但torch.jit.script不支持Python的动态语法，因此原始训练脚本中包含torch.jit.script时，使用自动迁移功能会产生冲突。若您的训练脚本中必须使用torch.jit.script功能，请使用手动迁移方法，进行迁移。

自动迁移方法会自动替换init_process_group中的backend值替换为tccl，但如果代码中包含backend判断的逻辑代码，例如：assert backend in ['gloo', 'nccl']、if backend == 'nccl'，则不会自动替换判断代码中的backend值，需要您手动将nccl修改为写为tccl。

操作步骤
方法一：导入自动迁移代码
导入自动迁移模块：在模型训练脚本中，添加from torch_sdaa.utils import cuda_migrate模块代码。示例如下：

from torch_sdaa.utils import cuda_migrate  # 使用torch_sdaa自动迁移方法
（推荐）开启自动混合精度AMP：如果原始模型中没有使用AMP，建议您在模型迁移时添加AMP进行训练。针对float16类型的卷积和矩阵乘法的运算，太初AI加速卡在软件层次进行了深度优化，使用AMP计算可以极大提升性能。

提示： 
针对卷积计算，太初当前软件栈仅存在float16类型的实现。所以在存在卷积计算的模型中，即使不使用autocast，也需要添加`GradScaler`相关代码，避免float16类型出现数值溢出导致精度下降的问题。

开启AMP的示例代码如下：

...
from torch.sdaa import amp              # 导入AMP
scaler = torch.sdaa.amp.GradScaler()    # 定义GradScaler
...
for epoch in range(epochs):
    for imgs, labels in train_dataloader:
        imgs, labels = imgs.to(device).to(memory_format=torch.channels_last), labels.to(device) 
        with torch.sdaa.amp.autocast():   # 开启AMP环境
            outputs = model(imgs)    
            loss = loss_func(outputs, labels) 
        optimizer.zero_grad()
        scaler.scale(loss).backward()    # loss缩放并反向转播
        scaler.step(optimizer)    # 参数更新
        scaler.update()    # 基于动态Loss Scale更新loss_scaling系数
（推荐）开启分布式训练DDP：如果原始模型中没有使用DDP，建议您在模型迁移时添加DDP，使用多个SDAA计算设备进行训练，以提升模型训练效率。

以torchrun为例，开启DDP的示例代码如下：

说明： 
更多DDP的启动方法，请参考分布式训练示例。

...
# 导入DDP所需的依赖库
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
# # 设置IP:PORT，框架启动TCP Store为ProcessGroup服务
os.environ['MASTER_ADDR'] = 'localhost' # 设置IP
# 从外部获取local_rank参数
local_rank = int(os.environ.get("LOCAL_RANK", -1))

def main():
    # DDP backend初始化
    # rank号和device一一对应，进行set device
    # 需要在初始化ProcessGroup之前进行set device，tccl限制
    device = torch.device(f"sdaa:{local_rank}")
    torch.sdaa.set_device(device)
    # 初始化ProcessGroup，通信后端选择tccl
    torch.distributed.init_process_group(backend="tccl", init_method="env://")
    ...
    ddp_model = DDP(model) # DDP model
    ...
保存并执行模型脚本，可参考运行模型训练。

方法二：设置自动迁移环境变量
（推荐）在模型运行脚本中，开启自动混合精度AMP、分布式训练DDP。

开启自动混合精度AMP：如果原始模型中没有使用AMP，建议您在模型迁移时添加AMP进行训练。针对float16类型的卷积和矩阵乘法的运算，太初AI加速卡在软件层次进行了深度优化，使用AMP计算可以极大提升性能。

提示： 
针对卷积计算，太初当前软件栈仅存在float16类型的实现。所以在存在卷积计算的模型中，即使不使用autocast，也需要添加`GradScaler`相关代码，避免float16类型出现数值溢出导致精度下降的问题。

开启AMP的示例代码如下：

...
for epoch in range(epochs):
    for imgs, labels in train_dataloader:
        imgs, labels = imgs.to(device).to(memory_format=torch.channels_last), labels.to(device) 
        with torch.sdaa.amp.autocast():   # 开启AMP环境

            loss = loss_func(outputs, labels)

        scaler.step(optimizer)    # 参数更新
        scaler.update()    # 基于动态Loss Scale更新loss_scaling系数

执行模型脚本，可参考运行模型训练。

执行结果
运行模型训练后，如果生成权重文件，则说明模型迁移成功。

说明： 
在自动迁移模型时，如果存在不支持的算子，会出现如下提示：

Torch-SDAA migrate unsupports "<api_name>" api. Please report a requirement to Torch-SDAA.
